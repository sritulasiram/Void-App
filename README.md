## Overview

**Void** is a Final Year Project developed by **Group DEM5C-G6**, built to address the inefficiencies in managing final year projects — from time-consuming meetings and unclear guidelines to scattered documentation. The app provides a centralized platform for communication, document submission, and progress tracking across students, supervisors, and coordinators throughout the entire project lifecycle.

---

## Features

### 👨‍🎓 For Students
| Feature | Description |
|---|---|
| 🔐 Login & Registration | Secure access to the application |
| 💬 Chat | Communicate directly with supervisors and coordinators |
| 📁 Project Data | View and manage project details |
| 📤 Upload Forms | Submit required documents digitally |
| 📞 Contact | Reach out to project stakeholders |
| 🔔 Notifications | Stay updated on milestones and announcements |
| ⚙️ Settings | Customize app preferences |
| ❓ Help & Feedback | Access support and suggest improvements |

### 🧑‍💼 For Coordinators
| Feature | Description |
|---|---|
| 🔐 Login & Registration | Secure access to the application |
| 💬 Chat | Engage with students and supervisors |
| 🗂️ Create Classes/Groups | Organize students into project groups |
| 📅 Create Sessions | Schedule and manage project activities |
| 📥📤 Download/Upload Forms | Manage all project documentation |
| 👁️ View Student Data | Monitor student project progress |
| 📢 Create Notifications | Broadcast updates to students |
| ❓ Help & Feedback | Access support and provide input |

## Getting Started

### Viewing the UI Designs
1. Download and install [Adobe XD](https://www.adobe.com/products/xd.html).
2. Clone or download this repository.
3. Navigate to the `designs/` folder.
4. Open any `.xd` file in Adobe XD.
